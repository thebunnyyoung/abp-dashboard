Instagram

Not connected
Now pulled through Metricool. Instagram follower count comes through the Data Proxy using your existing Metricool token, so it does not expire every 60 days and these two fields can stay blank. Add METRICOOL_TOKEN in Netlify. The Access Token and User ID fields are only a fallback if you ever switch to the direct Meta API.

Simplero

Not connected
Where to get it: Simplero admin, then Account Settings, then the API tab. A CORS proxy may be needed for browser calls. See the README for the Netlify Functions setup.

HubSpot

Not connected
Where to get it: HubSpot, then Settings, then Integrations, then Private Apps. Create an app with crm.objects.contacts.read and crm.objects.deals.read scopes. The token starts with pat-na1-.

Trello

Not connected

Data Proxy

Not set
What this is: Simplero and HubSpot block direct calls from a web page. This is the free Netlify proxy that fixes that. Paste the Netlify URL here and both pull through it, with the keys kept safe on Netlify. Setup steps are in the abp-dashboard-proxy README.

Q4 Pipeline (Google Sheets)

Not set
Why it works this way: this dashboard is public on GitHub, so your client list never goes into it. The Q4 tab signs in with Google and reads your private tracker Sheet only while the page is open. Anyone who can't open the Sheet sees nothing.
One-time setup, about 10 minutes (Gino can do it):
  1. Go to console.cloud.google.com and open the project you use for YouTube, or create a new one.
  2. Open APIs & Services, then Library. Search for Google Sheets API and click Enable.
  3. Open APIs & Services, then OAuth consent screen, then Get started. Name the app ABP Dashboard. For Audience, choose Internal if everyone signs in with a bunnyyoung.com Google account. Otherwise choose External, then add your Google email and your EA's as test users on the Audience tab.
  4. Open the Clients tab, click Create client, pick Web application, and add https://thebunnyyoung.github.io under Authorized JavaScript origins. Click Create and copy the Client ID. You don't need the secret.
  5. Paste the Client ID and the tracker link above, click Save, then Test Connection and sign in. If Google says the app isn't verified, click Continue. That's normal for a private app only your team uses.
  6. Share the tracker with your EA as an Editor, then click Copy setup link for your EA and send it to them. Opening that link sets up their browser in one step.

GitHub Deployment

First push. Run these from inside the abp-dashboard folder.
# config.js is never added, so keys stay private git init git add index.html README.md .gitignore git commit -m "Initial ABP dashboard" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/abp-dashboard.git git push -u origin main
Then turn on GitHub Pages: your repo on GitHub, then Settings, then Pages. Source: Deploy from a branch. Branch: main. Folder: / (root). Save. Two minutes later the dashboard is live at https://YOUR_USERNAME.github.io/abp-dashboard
Weekly update after that:
git add index.html README.md git commit -m "Weekly update" git push
